1. 核心比喻：截肢與重建

跟 recursive_ot 的「翻譯+平均」思路不同，reconstruct_ot 想的是「把被拿掉的東西補回來」

在 dad 自己 的原生網路裡，第 ℓ 層上半神經元的輸出是：

dad輸出[i] = Wd[i,:ih] @ hdad上半 + Wd[i,ih:] @ hdad下半

Wd[:oh, ih:]（四象限的右上角）在 dad 自己的網路裡本來就有真實功能——它負責處理 dad 自己的下半神經元。

拼接瞬間發生的事

create_dual_channel_policy 把子代前一層的下半，換成了 mom 的神經元。這一瞬間，dad 上半神經元賴以生存的「dad 下半」被截肢了——右上角那塊權重還在，但它面對的輸入已經不是它認識的東西。

重建的想法

如果能找到一個翻譯矩陣，把「mom 下半的訊號」翻譯成「dad 自己下半原本該有的樣子」，那麼 dad 自己的右上區塊權重就可以繼續正常運作——不是「融合」父母，而是「修復」dad 原本被截斷的迴路。

2. 重建公式怎麼推出來的

要讓 dad 上半神經元完全不崩，交叉通道 X_md 必須滿足：

X_md @ hmom下半 ≈ Wd[:oh, ih:] @ hdad下半

左邊是「子代實際會算出來的東西」，右邊是「dad 自己原本會算出來的東西」——目標是讓兩者盡量相等。

如果有一個傳輸矩陣 Tbb 能把「mom 下半的激活」翻譯成「dad 下半的激活」（Tbb @ hmom下半 ≈ hdad下半），代入上式：

X_md = Wd[:oh, ih:] · Tbb
Wdd不動 X_md = Wd[:oh,ih:]·Tbbdad 自己的右上區塊 × T_bb
X_dm = Wm[oh:,:ih]·Tttmom 自己的左下區塊 × T_tt Wmm不動

T_bb 跟 T_tt 各自比對誰

  • T_bb（重建 X_md 用）：比對「dad 自己下半」vs「mom 自己下半」——兩邊都是「母系血統」的神經元，角色對得上
  • T_tt（重建 X_dm 用）：比對「dad 自己上半」vs「mom 自己上半」——兩邊都是「父系血統」的神經元

跟 recursive_ot 最大的不同：沒有平均

這是重建單一血統的訊號，不是融合兩個血統——最終寫入的值只跟 dad（或 mom）自己有關，不會拿去跟對方平均。

6. 跟 recursive_ot_initialize_crosstalk 的差異

recursive_ot_initialize_crosstalkreconstruct_ot_initialize_crosstalk
核心思路翻譯 + 平均（融合兩個血統）翻譯 + 重建（修復被截斷的單一血統）
T 的比對依據交叉通道本身（鏡像位置）純通道（同血緣半層：上半vs上半、下半vs下半）
T 鏈的關係單一 T 鏈，逐層遞迴傳遞（上一層 T 會參與這一層 T 的計算）T_bb / T_tt 每層獨立算，互不依賴
第一層怎麼處理覆寫成 Wd_pure / Wm_pure完全不動，維持原始拼接值
最終有沒有平均有（0.5 × 翻譯值 + 對方那格）沒有（純粹重建，不摻對方）
寫入的權重來源純通道 Wd_pure / Wm_pure交叉通道本身 Wd[:oh,ih:] / Wm[oh:,:ih]

7. 已知限制（實驗誠實記錄）

目前實測結果

用 dad = model3、mom = model2（各自 baseline ≈ 308 分）實測，ot_reconstruct 在沒有搭配真正訓練時，child 評估 reward 為 -85.72——雖然理論上第一層精確、只有第二層有 OT 殘留誤差，但結果仍落在「機器人幾乎立刻摔倒」的區間，跟其他公式版本（-77 ~ -133）同一量級，沒有顯著突破。

目前最可信的解釋：網路很淺（僅 2 層隱藏層），唯一有殘留誤差的第二層直接接上 action_net、沒有任何緩衝層去稀釋它；且 action_net 本身目前完全沒有被 OT 對齊處理。

下一步方向

初始化本身提供的是「比隨機好」的起點，真正修正殘留誤差可能仍需要密集監督訊號（蒸餾）或足夠的線上訓練介入。
